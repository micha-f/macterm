What's New

  • Cell backgrounds painted by TUIs like helix, btop, and nvim now follow the window opacity when ghostty's background-opacity-cells is enabled, instead of rendering fully opaque over a translucent window. (#306)
  • Unfocused split panes now dim according to unfocused-split-opacity and unfocused-split-fill in your ghostty config. (#305)

Fixes

  • Holding a character key in a pane now repeats it instead of popping macOS's accent-picker overlay, so held keys drive motion in TUIs again. (#308)

Notes

  • Macterm's own Unfocused Dimming setting has been removed and a previously tuned value is not carried over — set unfocused-split-opacity in your ghostty config to adjust the dim.

Thanks to @thdxg for this release.
