What's New

  • New settings choose where a new tab and a new split start — the project folder or the active pane's current directory. Tabs still default to the project and splits to the active pane, so nothing changes until you pick otherwise. (#337)

Fixes

  • The adaptive background now only follows a color that reaches across the pane, so a bright slide or image filling part of a terminal no longer repaints the whole window. (#335)
