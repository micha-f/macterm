What's New

  • Double-clicking a tab or project name in the sidebar now opens its rename field. (#330, #333)
  • Cmd+digit reaches tabs past nine: while Command stays held, further digits build up a wider tab number, so ⌘1 then 2 selects tab 12. (#326)
  • macterm tab rename sets a tab's title from the command line, and --reset puts it back to automatic naming. (#323)
  • macterm project rename and macterm project remove manage the project list from the command line. (#327)
  • macterm pane run --no-submit leaves a command sitting unsubmitted on the pane's prompt instead of running it. (#328, #332)

Fixes

  • Peeking at the hidden sidebar no longer resizes the terminal underneath it — the sidebar now slides over the panes and leaves their layout untouched. (#280)

Notes

  • A bare ⌘0 still resets the font size; zero addresses a tab only as a continuation digit.
