What's New

  • Remote panes now reconnect themselves after a dropped connection (sleep, a network change) instead of sitting on a dead-pane screen until you quit and relaunch — the session keeps running on the host and its scrollback is replayed into the recovered pane. (#291)
  • Remote sessions left behind on a host that was unreachable when a pane closed are now cleaned up automatically, and only ever the ones this Mac created. (#291)
  • Close Tab is now a command in the palette, the File menu, and Settings → Keymaps as a rebindable shortcut (unbound by default), closing the active tab whether it is pinned or not. (#293)

Fixes

  • Typing in a pane no longer stops working when focus leaves it in the middle of an IME composition. (#296)
  • Macterm now merges every Ghostty config file Ghostty itself merges, instead of loading only one of them and dropping valid overrides. (#292)
  • Dragging a pane now previews one predictable drop target on the pane under the cursor, rather than two different shapes for the same result. (#294)

Notes

  • Automatic reconnection can be turned off in Settings → General → Remote Projects — useful on hosts whose SSH keys are Touch ID-gated, where waking with several dropped panes means several prompts.
  • The pinned tab context menu's "Remove from Pinned" is gone; Unpin Tab is the removal path, and it now also works on an unloaded (dimmed) pinned row.
  • Dropping a pane onto a divider to make thirds is no longer reachable by dragging.
