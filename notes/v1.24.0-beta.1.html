What's New

  • The ssh shell-integration features (ssh-env, ssh-terminfo) now work without Ghostty.app installed: Macterm itself installs its terminfo on the host at first connect and forwards truecolor, and the same engine is available directly as macterm ssh. (#274)
  • Folder permissions (Documents, Downloads, …) now survive updates instead of resetting on every release, and Settings warns when Full Disk Access is off, with a shortcut to grant it. (#273)
  • The quick terminal's position and size can each be set to Fixed or Dynamic in Settings. (#267)
  • Disabled settings are now visibly dimmed across the Settings window. (#268)

Fixes

  • The quick terminal now honors the liquid glass appearance setting. (#269)
  • Dragging the quick terminal by its strip now shows a grabbing hand. (#270)
  • The sidebar now reopens at the width you left it at, instead of a content-derived default. (#264)

Notes

  • The terminfo install now also works on hosts whose login shell isn't POSIX (nushell, fish). The path shell-integration feature is permanently off — Macterm ships no ghostty CLI to put on your PATH.
  • The first update from an earlier release resets folder permissions one last time (the signing identity became stable); grants stick from then on.

Thanks to @thdxg for this release.
