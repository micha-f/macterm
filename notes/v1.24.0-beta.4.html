What's New

  • Tabs can now be pinned above the projects in the sidebar: a pinned tab belongs to no project, survives restarts, and restores itself — re-running its commands — whenever its session dies. (#285)
  • A new setting (Settings → Appearance → Sidebar) keeps an AI agent's logo on a busy tab instead of the spinner; the unread-message dot still appears either way. (#287)

Fixes

  • Terminal panes now identify themselves as editable text to accessibility clients, so dictation apps can insert text into the focused terminal. (#283)
  • Macterm now picks up Ghostty's current default config file (config.ghostty) automatically, while still supporting the legacy config name. (#282)
  • Dragging the sidebar divider now stops at the sidebar's maximum width instead of letting it take over the window. (#286)

Thanks to @thdxg and @halms for this release.
