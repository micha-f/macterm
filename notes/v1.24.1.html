What's New

  • Settings → Appearance → Sidebar now has an Icon size option, so the project and tab icons can sit smaller beside the names. (#303)
  • Notifications now name the pane they came from, offer a Show button that jumps straight to it, and clear themselves from Notification Center once you've looked at that pane. (#300)

Fixes

  • Terminal notifications play the default system sound again. (#298)
  • An unloaded project's tab rows are dimmed, so a project whose shells have been stopped no longer looks identical to a running one. (#304)
  • A closed pinned tab keeps its pin icon instead of showing a crossed-out pin, which suggested it had been unpinned. (#304)
  • Dragging a tab to the top of the sidebar no longer stacks a "Pin Tab" band on top of the insertion line; the band appears only when nothing is pinned yet. (#299)
