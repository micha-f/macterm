What's New

  • Tabs can now be pinned above the projects in the sidebar: a pinned tab belongs to no project, survives restarts, and restores itself — re-running its commands — whenever its session dies. (#285)
  • Remote panes now reconnect themselves after a dropped connection (sleep, a network change) instead of sitting on a dead-pane screen until you quit and relaunch — the session keeps running on the host and its scrollback is replayed into the recovered pane. (#291)
  • Remote sessions left behind on a host that was unreachable when a pane closed are now cleaned up automatically, and only ever the ones this Mac created. (#291)
  • The ssh shell-integration features (ssh-env, ssh-terminfo) now work without Ghostty.app installed: Macterm itself installs its terminfo on the host at first connect and forwards truecolor, and the same engine is available directly as macterm ssh. (#274)
  • Folder permissions (Documents, Downloads, …) now survive updates instead of resetting on every release, and Settings warns when Full Disk Access is off, with a shortcut to grant it. (#273)
  • A new "Background SSH connections" setting (Settings → General) lets remote projects on hosts with Touch ID-gated SSH keys skip Macterm's background connections, so authentication only ever prompts for a pane's own connection. (#278)
  • The quick terminal's position and size can each be set to Fixed or Dynamic in Settings. (#267)
  • The quick terminal is now enabled and disabled by setting or clearing its keybind, replacing the separate Enable toggle. (#275)
  • A new setting (Settings → Appearance → Sidebar) keeps an AI agent's logo on a busy tab instead of the spinner; the unread-message dot still appears either way. (#287)
  • Close Tab is now a command in the palette, the File menu, and Settings → Keymaps as a rebindable shortcut (unbound by default), closing the active tab whether it is pinned or not. (#293)
  • Disabled settings are now visibly dimmed across the Settings window. (#268)

Fixes

  • Typing in a pane no longer stops working when focus leaves it in the middle of an IME composition. (#296)
  • Terminal panes now identify themselves as editable text to accessibility clients, so dictation apps can insert text into the focused terminal. (#283)
  • Macterm now picks up Ghostty's current default config file (config.ghostty) alongside the legacy config, and merges every location Ghostty itself merges instead of loading only one and dropping valid overrides. (#282, #292)
  • The sidebar now reopens at the width you left it at, instead of a content-derived default. (#264)
  • Dragging the sidebar divider now stops at the sidebar's maximum width instead of letting it take over the window. (#286)
  • Settings now correctly shows the Full Disk Access banner when access hasn't been granted. (#277)
  • Remote projects no longer re-trigger Touch ID prompts from the background tab-naming probe. (#276)
  • The quick terminal now honors the liquid glass appearance setting. (#269)
  • Dragging the quick terminal by its strip now shows a grabbing hand. (#270)
  • Dragging a pane now previews one predictable drop target on the pane under the cursor, rather than two different shapes for the same result. (#294)

Notes

  • Updating from an earlier release resets folder permissions one last time — the signing identity became stable in this release, so grants stick from then on.
  • The terminfo install also works on hosts whose login shell isn't POSIX (nushell, fish). The path shell-integration feature is permanently off — Macterm ships no ghostty CLI to put on your PATH.
  • Automatic reconnection of remote panes can be turned off in Settings → General → Remote Projects — useful on hosts whose SSH keys are Touch ID-gated, where waking with several dropped panes means several prompts.
  • The pinned tab context menu's "Remove from Pinned" is gone; Unpin Tab is the removal path, and it now also works on an unloaded (dimmed) pinned row.
  • Dropping a pane onto a divider to make thirds is no longer reachable by dragging.
